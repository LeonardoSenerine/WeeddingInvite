# Convite de Casamento

Site estático (HTML/CSS/JS, sem build) com convite, contagem regressiva, informações do evento,
confirmação de presença via WhatsApp e lista de presentes.

## Como editar
Todos os dados ficam em **`config.js`**: nomes, data/hora, local, traje, contatos do RSVP,
chave Pix, lista de presentes e fotos. Itens marcados com `TODO` ainda precisam ser confirmados.

- Fotos do casal: `assets/img/`
- Fotos do local: coloque em `assets/img/local/` e liste em `fotosLocal` no `config.js`

## Publicar (GitHub Pages)
Settings → Pages → Deploy from a branch → escolha a branch e a pasta `/ (root)`.
